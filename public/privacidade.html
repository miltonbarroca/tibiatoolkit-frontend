Política de Privacidade

Última atualização: maio de 2026

Dados coletados

Coletamos apenas e-mail e dados de pagamento necessários para a assinatura. Não compartilhamos dados com terceiros, exceto a Stripe para processamento de pagamentos.

Armazenamento

Os dados são armazenados em servidores seguros. Senhas são armazenadas com hash bcrypt.
